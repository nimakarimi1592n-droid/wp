جزوه آموزش HTML-ارسلان تراب زاده

۱. HTML چیست؟

HTML مخفف HyperText Markup Language است. از HTML برای ساختاردهی صفحات وب استفاده می‌شود. با استفاده از HTML می‌توان عنوان، متن، تصویر، لینک و جدول در سایت قرار داد.

۲. سینتکس چیست؟

سینتکس (Syntax) به معنی قوانین نوشتن کد است. هر زبان برنامه‌نویسی یا زبان نشانه‌گذاری قوانین مخصوص خودش را دارد. اگر کدها را اشتباه بنویسیم ممکن است درست اجرا نشوند.

<h1>سلام دنیا</h1>

در این مثال تگ باز و بسته شده و متن داخل آن قرار گرفته است.

۳. ساختار اصلی HTML

هر صفحه HTML دارای یک ساختار اصلی است:

<!DOCTYPE html>
<html>
<head>
<title>My Website</title>
</head>
<body>
<h1>سلام</h1>
</body>
</html>

  • DOCTYPE نوع سند را مشخص می‌کند.
  • html تگ اصلی صفحه است.
  • head شامل اطلاعات صفحه است.
  • title عنوان صفحه را مشخص می‌کند.
  • body محتوای قابل مشاهده سایت را در خود قرار می‌دهد.

۴. پاراگراف و هدینگ

برای نوشتن عنوان از تگ‌های h1 تا h6 استفاده می‌کنیم. h1 بزرگ‌ترین عنوان و h6 کوچک‌ترین عنوان است. برای نوشتن پاراگراف نیز از تگ p استفاده می‌شود.

<h1>عنوان اصلی</h1>
<h2>عنوان دوم</h2>
<p>این یک پاراگراف است.</p>

۵. اتریبیوت‌ها (Attributes)

اتریبیوت‌ها ویژگی‌هایی هستند که به تگ‌های HTML اضافه می‌شوند و اطلاعات بیشتری درباره آن‌ها می‌دهند.

<img src="1.png" width="300" height="200">

  • src مسیر تصویر را مشخص می‌کند.
  • width عرض را مشخص می‌کند.
  • height ارتفاع را مشخص می‌کند.
  • href آدرس لینک را مشخص می‌کند.
  • style برای تغییر ظاهر تگ استفاده می‌شود.

۶. لینک‌ها و تصاویر

برای ساخت لینک از تگ a و برای نمایش تصویر از تگ img استفاده می‌کنیم.

<a href="https://www.google.com">ورود به گوگل</a>

<img src="1.png" width="300">

۷. تگ‌های قالب‌بندی متن

با این تگ‌ها می‌توان ظاهر نوشته‌ها را تغییر داد.

  • b: ضخیم کردن متن
  • strong: مهم نشان دادن متن
  • i: کج کردن متن
  • small: کوچک کردن اندازه متن
  • del: خط زدن روی متن
  • mark: هایلایت کردن متن
  • br: رفتن به خط بعد
  • hr: ایجاد خط افقی

۸. فاوآیکون (Favicon)

فاوآیکون تصویر کوچکی است که کنار عنوان سایت در تب مرورگر نمایش داده می‌شود. برای اضافه کردن آن از تگ link استفاده می‌کنیم.

<link rel="icon" href="favicon.png">

۹. جدول‌ها (Table)

برای ساخت جدول از تگ table استفاده می‌کنیم. tr برای ساخت سطر، th برای عنوان ستون و td برای خانه‌های جدول است.

<table border="1">
  <tr>
    <th>نام</th>
    <th>سن</th>
  </tr>
  <tr>
    <td>نیما</td>
    <td>۱۳</td>
  </tr>
</table>

۱۰. لیست‌ها (List)

لیست‌ها برای مرتب کردن اطلاعات استفاده می‌شوند. دو نوع لیست اصلی در HTML وجود دارد:

  • ul: لیست نامرتب که با نقطه نمایش داده می‌شود.
  • ol: لیست مرتب که با شماره نمایش داده می‌شود.
  • li: برای نوشتن هر مورد در لیست استفاده می‌شود.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>مرحله اول</li>
  <li>مرحله دوم</li>
</ol>

۱۱. رنگ‌ها در HTML و CSS

برای تغییر رنگ نوشته و پس‌زمینه از CSS استفاده می‌کنیم. رنگ‌ها را می‌توان با نام، کد HEX یا RGB مشخص کرد.

<p style="color: red;">متن قرمز</p>
<p style="color: #0000ff;">متن آبی</p>
<p style="color: rgb(0,255,0);">متن سبز</p>

۱۲. استایل‌دهی (CSS)

CSS برای زیباتر کردن صفحات وب استفاده می‌شود. با CSS می‌توان رنگ، اندازه متن، فاصله، پس‌زمینه و حاشیه را تغییر داد.

<style>
  body {
    background-color: gray;
  }
  h1 {
    color: white;
    text-align: center;
  }
</style>

۱۳. چند نکته کاربردی در VS Code

در برنامه Visual Studio Code می‌توان با نوشتن html:5 و زدن کلید Enter ساختار اولیه یک فایل HTML را به صورت خودکار ایجاد کرد.

همچنین با نوشتن lorem و زدن Enter می‌توان یک متن نمونه ایجاد کرد. این متن برای پر کردن موقت صفحه و آزمایش ظاهر سایت استفاده می‌شود.

۱۴. ویژگی‌های مهم CSS

ویژگی کاربرد
color تغییر رنگ متن
background-color تغییر رنگ پس‌زمینه
font-size تغییر اندازه متن
text-align تنظیم محل قرارگیری متن مثل center
direction تعیین جهت متن مثل rtl و ltr
border ایجاد حاشیه
margin ایجاد فاصله بیرونی

۱۵. نکات مهم

  • بیشتر تگ‌های HTML دارای تگ باز و بسته هستند.
  • نام تگ‌ها داخل علامت‌های < و > نوشته می‌شود.
  • برای نمایش تصویر باید مسیر آن درست باشد.
  • برای ساخت لینک از href استفاده می‌کنیم.
  • برای زیباسازی سایت از CSS استفاده می‌شود.
  • برای راست‌چین کردن صفحه فارسی از dir="rtl" استفاده می‌کنیم.
  • برای وسط‌چین کردن متن از text-align: center استفاده می‌کنیم.
